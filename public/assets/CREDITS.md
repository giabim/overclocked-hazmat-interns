# Overclocked asset credits

All lab floor markings, panel wear, tile bump maps, walls, props, intern models, specimens, canisters, and sounds in v3 are generated in application code. No external texture, model, audio, or environment-image files are downloaded. PMREM reflections use Three.js RoomEnvironment.

- Three.js 0.186.1 and its addons: MIT, https://github.com/mrdoob/three.js/blob/dev/LICENSE
- Lucide icons: ISC, https://lucide.dev/license

The v3 code-generated assets are distributed with this repository's code. No third-party CC0 files were needed.
